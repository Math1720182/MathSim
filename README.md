# Math-Sim

Math-Sim is an educational website where you can find mathematical simulations on various topics. The first simulation is a queue simulator, adapted for theme parks, where you can simulate a queue following an M/D^B/1 model.

This website allows me to develop my coding and math skills through various simulations, with the aim of preparing myself for my Master's degree.

Please don't hesitate to contact me if you need more information about the algorithms or if you want a specific simulation!
